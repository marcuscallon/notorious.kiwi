# assets/clients/

Real brand marks for the clients wall (marks mode). Normalised: transparent
PNG, height <= 96px, width <= 400px, trimmed.

- `src/` - original fetched sources (SVG/PNG) for provenance and re-processing.
- Top-level *.png - display versions; references from content/clients.md
  via "img:<file>" entries, with per-logo dark-theme modifiers:
  - `chip`  - dark artwork shown on a light card (.lm-chip)
  - `invert`- black artwork inverted to white (.lm-inv)

Sources: Wikimedia Commons (Special:FilePath), official sites (NTI, Petronas,
Save the Children, Greenroom, Bright Innovation, Oxfam, Virgin Media, RAPP,
St Paul's). No public brand asset exists for: Blind Eye Films, The Global Mail
(defunct), Inspire (ambiguous), WaterAid, Hearis, Open Telecommunications,
Provenco, Queensland Transport.

Trademarks remain property of their owners; shown here as nominative "clients
I have worked with" usage on a personal profile. Barnardos/RACQ source files
are marked non-free on Wikipedia; nominative use in this context is the intent.
